# Peppa – músarleikur

Einfaldur leikur til að æfa notkun tölvumúsar.

## Hvernig leikurinn virkar
- Nemandi smellir á Peppu, heldur músarhnappnum inni og dregur hana að húsinu.
- Leikurinn hefur 10 stig sem verða smám saman erfiðari.
- Hvert stig þarf að klára 5 sinnum til að opna næsta stig.
- Framvinda vistast sjálfkrafa í vafranum með `localStorage`.
- Hægt er að velja öll áður opnuð stig af upphafssíðunni.
- Hægt er að setja leikinn í fullskjá og kveikja/slökkva á hljóði.

## Keyrsla
Opnaðu `index.html` beint í vafra eða birtu repository-ið með GitHub Pages.
